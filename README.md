## 🛠️ Technology Stack

* **Styling:** Tailwind CSS v4 with custom dark technology theme tokens

## 🚀 Getting Started

### Prerequisites

* Node.js 18.18+ (tested on Node v24)
* npm, pnpm, or yarn

### Installation

```bash
git clone https://github.com/Sureshb11/sureshbala.git
cd sureshbala
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
